# Byblos Car Rental Platform

This repository preserves the Android project configuration from my Byblos car-rental coursework. The project idea was to support customers and branch staff in a car-rental application.

## What is included

- An Android application module and its Gradle project files.
- AndroidX navigation and ViewBinding declarations.
- Firebase Realtime Database and Analytics integration declarations.
- Test-library declarations and a sample Firebase configuration.

## Repository scope

The current public snapshot contains the project scaffold. The application source directory has no screens or business logic, so this repository does not demonstrate working vehicle search, customer registration, or booking flows.
